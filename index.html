¿Qué es la Maceta IoT?

Es un sistema inteligente que monitorea y optimiza el cuidado de las plantas mediante sensores y algoritmos de machine learning. Analiza en tiempo real las condiciones ambientales y del suelo para predecir necesidades de riego y otros cuidados, mejorando así la salud de la planta de manera autónoma.

Algunos Sensores Utilizados

DHT11

Sensor de temperatura y humedad

Sensor de CO2

Monitoreo de calidad del aire

Sensor de luz

Detección de niveles de iluminación

Tecnologías Utilizadas

Raspberry Pi / ESP32, sensores DHT11, CO2, Firebase, Machine Learning.

Comportamiento del Modelo de Machine Learning

Predicción de riego basada en temperatura y humedad.
